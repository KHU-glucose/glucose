# 공통 UI 디자인 기준

2026-10-08 기준. 승인된 홈을 대표로 현재 42개 화면에 사용하는 방향입니다. 화면별 정보량에 맞춰 사용합니다.

## 레퍼런스

- LG ThinQ: 기능별 영역 구분, 제목과 필요한 보조 설명, 평면 리스트.
- 네이버페이·토스: 왼쪽 정렬, 값과 설명의 위계, 여백으로 정보 묶기.
- 해피문데이·카카오페이: 흰 배경과 제한적인 보조 색, 입력과 주요 행동 구분.
- 플랜핏: 일관된 하단 메뉴.
- 첨부 건강 지표·식사 UI: 넓은 그래프, 끝점 표시, 지표 우선 배치, 입력·리스트·CTA 강조.
- 인바디·보수계: 설정 묶음과 평면 목록, 기간 선택 탭, 핵심 수치와 설명의 강약.

화면 전체를 복제하지 않고 기능에 맞게 장점을 조합합니다. 수치가 먼저 읽히고 다음 행동이 명확해야 합니다. 반복 설명·장식용 영어 라벨·항목별 카드 남발을 피합니다.

## 글씨와 배치

Noto Sans KR. 화면 제목 22px Bold, 섹션 제목 18px Medium, 항목·본문·입력·버튼 16px, 보조 설명 14px를 중심으로 사용합니다. 승인된 홈과 핵심 수치, 그래프 눈금, 시스템 위젯은 각 역할에 맞는 크기를 유지합니다. 본문은 약 24–26px 행간이며 긴 제목은 자연스럽게 줄바꿈합니다.

본문 좌우 여백은 주로 24px입니다. 홈 그래프는 좌우 8px까지 넓게 사용하며, 분석 그래프는 왼쪽 36px를 축 숫자 공간으로 두고 y축선부터 곡선과 배경을 시작합니다. 홈 기록 버튼은 같은 너비 177px·높이 55px입니다. 입력·완료 버튼은 화면별 약 55–60px입니다. 긴 글은 고정 너비와 자동 높이로 줄바꿈합니다.

흰 주요 영역과 회색 배경으로 섹션을 구분합니다. 선택·입력·독립 행동처럼 필요한 부분에만 경계를 둡니다.

리포트·리뷰 탭은 회색 바탕에 선택한 항목만 노란색으로 강조합니다. 안내는 연한 회색 surface와 작은 제목·일반 본문으로 구분합니다. 대응 기록 단계와 프로필 확인 목록은 반복 카드 대신 평면 목록·구분선을 사용합니다.

## 그래프

- 홈·일간: 곡선 아래 연한 초록 채움.
- 주간·대응 리뷰: 70–180 구간 배경에 연한 초록 채움.
- 저혈당·고혈당 구간은 빨간 선 유지.
- 마지막 점에 동그라미: 범위 안 초록, 범위 밖 빨강.
- 마지막 x축 라벨은 초록 강조.
- 기록 번호의 세로 연결선과 기준선은 점선.
- 기록 표시를 해당 시점 점선 위에 놓고, 서로 겹치는 경우에만 최소한으로 벌린 뒤 짧은 사선 점선으로 연결합니다. 일간 인슐린 표시는 주사기 아이콘이며 실제 시간은 이동하지 않습니다.
- 홈 70·180·250 축 숫자는 그래프 안쪽에 배치해 가로 폭 확보.

주간 식사 비교는 같은 축을 쓰는 두 그래프로 분리하고 조건을 해당 그래프 아래에 둡니다. 요일별 비율은 정확한 값의 7열로 표시합니다. 저혈당 리뷰 1·2는 처음·추가 섭취, 고혈당 리뷰 1은 인슐린 투여이며 아래 행동·시간·양 행과 연결합니다.

## 기능별 구성

- 홈: 날짜·혈당 흐름 → 음식/인슐린 기록 버튼 → 음식 리스트.
- 입력: 주요 값 → 상황·시간·메모 → 저장.
- 리포트·리뷰: 핵심 값·그래프 → 기록 사실 → 다음 행동. 설명을 한꺼번에 쌓지 않습니다.
- 검색·설정: 주요 기능을 먼저 두고 관련 목록은 평면적으로 정렬.
- 음식 사진: 촬영 화면의 앨범에서 휴대폰 기본 사진 선택창을 열고 음식 확인으로 이동. 별도 앱 안내 화면 없음.

UI 정제는 기능 구현이나 의학적 판단 변경을 의미하지 않습니다.
