# 번호·기호·단위 재검토

최신 Figma 43개 화면의 표시된 번호·그래프 상태 기호·단위를 조사했습니다. 저혈당·고혈당 리뷰의 기록 번호는 앞서 추가한 행동·시간·양 행으로 연결되어 있습니다.

## 추가 수정

- 일간 리포트: 그래프와 투여 기록의 약자 I를 ‘투여’로 변경. 그래프 마커 배경을 22→40px로 늘려 두 글자를 표시. 범례도 ‘투여 기록’으로 맞춤. 혈당 좌표와 투여 시점은 유지.
- 홈·일간·주간·저혈당 리뷰·고혈당 리뷰: ‘▼ 낮음 / ▲ 높음’을 ‘저혈당 / 고혈당’으로 변경. 변화 방향으로 읽힐 수 있는 삼각 기호 대신 범위 밖 상태 이름을 직접 표시. 주간 일별 평균 설명도 같은 이름으로 변경. 수치와 빨간 구간은 유지.
- 잠금화면 위젯: 초속효성 프리셋 숫자 4→4 U로 단위를 명시. 앱에서 실제 투여 내용을 확인한다는 안내는 유지.

## 유지

- 홈·일간의 식사 번호는 아래 식사 목록에 같은 번호가 연결되어 있으므로 유지.
- 음식 확인의 조각 수, 인슐린 입력의 투여량은 가까운 항목 이름과 단위가 있으므로 유지.
- 기록 벌집의 날짜, 주간 랭킹의 순위·기록 일수는 화면 맥락으로 구분되어 유지.

수정된 일간 그래프와 위젯을 실제 표시로 확인했습니다. 전체 43개 화면의 표시된 텍스트가 부모 영역을 넘는 문제는 0건입니다. 임상 내용·기록값은 변경하지 않았습니다.

## 후속 수정

- 일간 인슐린 그래프 마커는 글자 대신 주사 아이콘으로 변경. 식사 3번 표시와 같은 높이·22px 크기로 맞췄습니다. 최종 배치는 겹치지 않는 최소 간격으로 조정하고 짧은 사선 점선으로 각각 실제 기록 시점에 연결합니다.
- 홈 혈당 그래프의 넓은 너비는 유지. 일간·주간·저혈당 및 고혈당 리뷰의 분석 그래프 7곳은 왼쪽 36px를 세로축 숫자 영역으로 두고, 그래프 곡선·배경을 세로축선부터 시작하도록 정렬했습니다.
- 세로축 범위·그래프 높이·기록값·시간은 유지했습니다. 분석의 정상 범위 초록색과 범위 밖 빨간 표시도 유지했습니다.
