# 현재 디자인 자료 정리

2026-10-08. 최신 UI는 Figma의 42개 화면입니다.

- 초기 9번 HTML과 2·3·4·5 참고 이미지 삭제.
- 디자인 비교·수정·검증·파일 정리 문서의 필요한 내용을 공통 디자인 기준·팀원 사용 안내에 통합. 최근 문서 원문 6개는 별도 삭제 승인이 확인될 때까지 보관.
- Figma의 숨겨진 이전 그래프·문구·미리보기와 사용처가 없는 이전 기록 카드·혈당 그래프 부품 삭제. 총 730개 레이어 정리.
- 현재 42개 화면과 사용하는 공통 부품, 최신 마스코트 자료 유지. 정리 후 화면 크기와 텍스트 경계 검사, 대표 리포트·설정 렌더링 확인.
- 기획·API 문서와 팀원 코드는 수정하지 않음. 이전 Git 커밋은 유지.

현재 자료: Figma 링크, 화면 목록, 공통 디자인 기준, 팀원 사용 안내, 최신 마스코트 자산·제작 기록, 기존 기획 문서. 파일 경로와 해시는 `design/manifest.json`에서 확인합니다.
