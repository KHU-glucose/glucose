# 디자인 파일 정리

2026-10-07. 최신 UI는 Figma를 기준으로 공유합니다.

## 제거

- 최신 Figma와 달라진 과거 전달 ZIP, 가져오기용 SVG, HTML 미리보기, 생성 스크립트, 상태 JSON, 과거 검증 이미지.
- 이전 마스코트 v1 시트 4개와 해당 프롬프트, 과거 모바일 UI 콜라주.
- 이전 사용·개발 전달 가이드와 중간 검토 문서는 최신 사용 안내·UI 기준·수정 내역으로 통합.
- 기존 작업 폴더에서 이미 삭제되어 있던 1–8번 및 번호 없는 HTML, 홈 후보 HTML, 5번 ZIP, 게이미피케이션 문서와 성장 이야기 이미지는 다시 복원하지 않음.

이번에 정리한 로컬 파일은 162개, 약 227MB입니다. 상당수는 아직 Git에 등록되지 않은 임시 결과물이었으므로 GitHub 변경 파일 수와 다릅니다. 정리 전 로컬 디자인 폴더는 Git에서 제외된 `.tools/cleanup-backups/`에 보관했습니다.

## 보관 및 갱신

- 최신 Figma 핵심·상세 페이지 링크와 대표 홈 링크.
- 실제 Figma에서 읽은 43개 화면의 ID·이름·크기·링크: `screen-index.json`.
- 팀원 사용 안내, 공통 UI 기준, 2026-10-07 수정 내역.
- 초기 9번 HTML, 사용자가 제공한 2·3·4·5 PNG.
- 마스코트 4종의 최신 2D 시트·앱 사용 장면 콘셉트 및 제작 프롬프트, 아이콘 시트, 기존 꿀벌 원본.
- 현재 남아 있는 기획·API 문서.
- `manifest.json`을 실제 보관 파일 기준으로 재작성.

최신 Figma 화면을 과거 로컬 SVG로 대체하지 않습니다. 이 저장소에는 Figma 링크와 디자인 기준을 반영하며 최신 화면의 `.fig` 또는 SVG 전체 백업은 포함하지 않습니다. 개발 코드와 팀 AI 활용 기록은 이번 정리 범위에서 수정하지 않았습니다.
