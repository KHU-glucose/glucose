# 마스코트별 앱 사용 장면 · v2

승인한 2D 캐릭터 방향을 바탕으로 앱 아이콘, 잠금화면 위젯, 알림, 마스코트 상세 화면을 제안합니다. 기본 이미지 생성 도구로 제작한 검토용 콘셉트 보드입니다. 실제 앱 및 Figma 적용 전 검토하며, 잠금화면 위젯은 단색 얼굴 형태로 표현합니다.
