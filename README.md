# Glubee

글루비의 디자인 시안, 캐릭터 이미지, 서비스 기획 및 개발 자료를 모은 저장소입니다.

## 결과물

| 폴더 | 내용 |
| --- | --- |
| `design/prototypes/` | HTML 디자인 프로토타입 및 홈 화면 시안 |
| `design/assets/` | 꿀벌 캐릭터 콘셉트, 벌집 성장 이야기, 모바일 UI 이미지 |
| `design/docs/` | 서비스 필요성, 차별점, 게이미피케이션, 개발 흐름, API 계약 문서 |
| `design/archives/` | 기존 디자인 ZIP 원본 |

[디자인 자료 안내](design/README.md)에서 대표 파일과 버전 정보를 확인하세요.

이 저장소의 HTML은 디자인 시안입니다. 서비스 구현 여부와 서버 연동은 각 파일의 내용을 기준으로 확인해야 합니다.
