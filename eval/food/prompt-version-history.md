# 음식 인식 프롬프트 버전과 커밋 정리

정리일: 2026-10-08. 기존에 보존한 프롬프트 원문을 기준으로 버전별 커밋을 나눴다.
과거 개발 당시의 전체 작업 디렉터리를 복구한 것은 아니다. 공통 평가 기능은 v1 보존
커밋에 함께 정리하고, 이후 커밋에 각 후보와 관련 기록을 추가한다. 커밋 날짜를 과거로 바꾸지 않는다.

| 버전 | 변경 의도 | 평가 상태 |
| --- | --- | --- |
| baseline-v1 | 기존 프롬프트 보존, 버전 선택·재현 가능한 평가 기반 | 개발용 10장 이름 6/10 |
| rules-v2 | 음식/비음식, 이름, 분류, 개수, 섭취 여부 규칙 명시 | 같은 10장 이름 3/10 |
| examples-v3 | 상세 규칙을 간결하게 정리하고 짧은 정책 예시 추가 | 첫 실행 7/10, 반복 5/10. 현재 운영 기본값 |
| focused-v4 | 대표 요리명·조리 방식·주재료의 이름 선택 문단 개선 | 첫 실행 7/10, 반복 4/10. 향상 입증 못 함 |
| contrast-v5 | 비슷한 음식의 시각적 구별 단서 추가 | 한 번의 실행 7/10. 우수성 입증 못 함 |
| glucose-v6 | 혈당 관리용 중요 음식 누락·조리법·제품 표시 관찰 강화 | 실제 사진 비교 미실행. 별도 기록 그룹 평가 및 구현 테스트 추가 |

점수는 같은 개발용 사진 10장에 대한 예비 결과이며 검증 세트 성능이 아니다.
API 실패도 분모에 포함한다. 모든 음식의 정답이 완비되지 않아 전체 precision/F1을
일반화할 수 없다. 모델, 이미지 detail/축소 크기, 출력 스키마는 변경하지 않았다.
새 후보를 추가했다고 운영 기본값을 최신 버전으로 바꾸지 않는다.

최초 비교는 `evidence/prompt-comparison-2026-10-07.json`, 추가 비교·반복은
`evidence/prompt-refinement-2026-10-07.json`, v6 구현 검증은
`evidence/glucose-policy-implementation-2026-10-08.json`에 보관한다.
독립 재분석 제안과 사전 점검 문서는 프롬프트 후보와 별도 문서 커밋으로 정리한다.

사진 데이터·실제 라벨·비밀키·원본 로컬 보고서·팀원의 별도 문서는 이 정리의 커밋 대상에서 제외한다.
