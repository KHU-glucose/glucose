# Food-101 평가용 사진 확보

다운로드 도구: `tools/download_food101.py`. 서비스 동작이나 프롬프트는 바꾸지 않는다.
OpenAI 호출, 모델 학습, 전체 사진 자동 평가도 수행하지 않는다.

## 저장 위치

```text
food_testing/food101/
  acquisition.json           # 고정된 출처 버전, 원본 파일 크기·SHA256
  source/data/*.parquet       # 전체 원본 11개 파일 (약 5.06 GB)
  source/README.md            # 원본 데이터 설명과 이용 조건
  images/train/<class>/       # 75,750장, 클래스별 750장
  images/validation/<class>/  # 25,250장, 클래스별 250장
  classes.json               # 101개 영어 클래스 매핑
  manifest.jsonl             # 사진별 출처, 클래스, 크기, SHA256
  download-summary.json      # 완료 시에만 생성되는 검증 결과
  progress.json              # 현재 추출 진행 상태
```

원본과 추출 사진을 함께 보관하므로 약 10 GB 이상과 101,000개 파일을 저장한다.
OneDrive 아래에 있으므로 사용자 설정에 따라 동기화 공간도 사용될 수 있다.
이 데이터 폴더는 `.gitignore`에 제외한다. 기존 한국 음식·식료품 데이터는 건드리지 않는다.

## 실행 / 재시작

Python에 `huggingface_hub>=0.32,<2`, `pyarrow>=18,<24`, `Pillow`가 필요하다.

```powershell
python eval/food/tools/download_food101.py
# 다운로드된 원본만으로 다시 검사/추출 (네트워크 접근 없음)
python eval/food/tools/download_food101.py --offline
```

출처: https://huggingface.co/datasets/ethz/food101
고정 버전: `83488de741c1bd1ce27aa6a2b33e19c7bdf92ca9`.
공식 Hub 다운로드 함수의 로컬 메타데이터로 이미 받은 파일을 재사용한다.
11개 원본 파일은 공개된 SHA256과 비교한다. 사진은 재압축하지 않고 원본 바이트를 저장한다.
모든 사진을 완전히 디코딩하여 손상 여부를 검사하고 분할별·클래스별 개수를 확인한다.
기존 이미지가 다른 내용이면 덮어쓰지 않고 중단한다. 동시 실행은 잠금으로 막는다.
추출 중 끊기면 완료 리포트가 없는 상태이며, 같은 명령을 다시 실행할 수 있다.
Windows/OneDrive의 일시적인 파일 잠금에는 최대 약 5초 동안 재시도한다.
사진 처리는 6개 작업 스레드와 64행 배치로 제한하며, 기록 순서와 파일 ID는 고정한다.
다른 버전이나 기존 사용자 파일이 있는 미등록 폴더는 재사용하지 않는다.

## 평가할 때 주의

- 원본 `train` 라벨에는 오류가 있을 수 있다. 개발용 후보 풀로 활용한다.
- 원본 `validation`은 검수된 원본 테스트 분할이다. 우리 프롬프트 수정에 사용하면
  우리 실험에서는 개발 데이터가 된다. 최종 평가용은 먼저 선정·봉인하고 수정에 사용하지 않는다.
- 바이트가 같은 사진은 SHA256으로 중복을 제외한다. 내용이 유사한 사진은 별도 육안 확인이 필요하다.
- 원본 영어 클래스는 대표 음식 하나에 대한 라벨일 뿐, 사진 속 모든 음식의 정답이 아니다.
  개수, 앱 카테고리, 당류·탄수화물, 혈당 관리 그룹은 포함되어 있지 않다.
- `manifest.jsonl`은 검색·선정용이며 `eval_food.py`용 확정 정답 파일이 아니다.
  `annotation_complete=false`를 유지한다. 선정 후 한국어 이름·보이는 부식·간식 개수 등을
  사람이 검수하여 별도 평가 라벨을 작성한다. 혈당 관리 그룹은 확인 가능한 정책 항목만 붙인다.
- 한식, 저혈당 처치 식품, 포장 제품, 음식 아닌 사진은 다른 데이터/직접 촬영으로 보충한다.
- Food-101 사진에 손·얼굴이 있을 수 있으므로 제출용 사진은 개인정보 여부도 확인한다.
- 다운로드 완료는 인식 정확도 개선이나 완료 기준 달성을 의미하지 않는다.

## 이용 조건

원본 카드의 라이선스는 `unknown`이며, ETHZ가 사진 저작권을 소유하지 않는다.
원본 설명은 scientific fair use를 넘어서는 사용에 사진 소유자와의 협의가 필요하다고 명시한다.
상업적 앱 사용·재배포 허용이 확인된 데이터로 취급하지 않는다. 공개 GitHub에 사진을 올리지 않는다.
팀 제출 시 데이터 출처와 Food-101 (Bossard, Guillaumin, Van Gool, ECCV 2014)을 표시한다.

## 실제 확보 결과 (2026-10-08)

- 전체 다운로드·추출 완료: 101,000장, 101개 종류.
- 원본 분할 유지: train 75,750장 / validation 25,250장.
- 원본 5,059,972,308 bytes, 추출 사진 5,116,621,947 bytes (합계 약 10.18 GB, 부가 파일 제외).
- 고유 이미지 SHA256 100,992개: 동일 바이트 중복분 8장. 분할 사이 중복 발생도 2건이므로
  최종 평가를 선정할 때 반드시 SHA256으로 개발용과 평가용이 겹치지 않게 제외한다.
  원본 전체 보존을 위해 다운로드 폴더에서 중복 사진을 삭제하지 않았다.
- 원본 11개 SHA256, 모든 사진 디코딩, 분할별 개수, 종류별 750/250장 확인 통과.
- 도구 오프라인 테스트 10개 통과. OneDrive 파일 잠금 오류를 재시도하도록 보완 후 완료.
- 다운로드 단계에서는 모델 성능 평가·프롬프트 변경·API 호출을 하지 않았다.
  이후 별도로 실행한 100장 v3 예비평가는 [결과 기록](v3-primary-results-2026-10-08.md)을 참고한다.
- 자세한 사진별 기록은 `food_testing/food101/manifest.jsonl`, 완료 결과는
  `food_testing/food101/download-summary.json`에 보관했다.
