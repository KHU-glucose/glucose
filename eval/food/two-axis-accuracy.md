# 음식 인식 정확도 두 축 — 2026-10-08

음식명 정확도와 혈당 관리용 특성 정확도를 별도로 표시한다. 둘을 평균하거나,
새 그룹 점수로 기존 음식명 점수를 대체하지 않는다.

최신 합의: [음식 계열을 먼저 맞힌 경우에만 영양 참고값 비교](family-gated-nutrition.md)를 추가했다.
아래 `management_group`은 기존 검수형 기록 그룹이며, 새 `food_family`(큰 음식 계열)와 다르다.
새 지표는 `accuracy_summary.family_gated_nutrition`에 저장한다. 같은 계열 일치를 영양 동등으로
인정하지 않으며 기존 이름·관리 그룹 점수를 바꾸지 않는다.

## 1. 음식명 정확도

`food_name_recall`: 사전에 고정한 음식명·동의어와 일대일 일치한 수 / 정답 음식 수.
실패·누락은 분모에 포함한다. 식사 개수 정책, 기존 완료 기준과 이름 채점은 바꾸지 않는다.
현재 100장 대표 클래스 예비평가의 71/100은 그대로 보존한다.

사진 전체 음식 정답이 완비되지 않으면 전체 precision/F1은 의미 있는 성능 지표로
표시하지 않는다. 새 요약에서는 null이며 CLI는 음식명 정밀도를 미측정으로 표시한다.
하위 `metrics`의 기존 필드는 호환성을 위해 그대로 남는다.

## 2. 혈당 관리용 특성 정확도

현재 구현의 핵심은 `management_group_recall`: 사전에 검수한 기록 그룹과 일대일 일치한 수 /
`management_group` 정답이 있는 음식 수다. **실제 혈당 상승량·반응의 정확도가 아니다.**
모든 혈당 관련 특성을 포괄하는 지표도 아니다. 현재 정의한 그룹은 일부 생선 조리법,
흰쌀밥, 일반/제로 콜라뿐이다. 범위와 근거는 [그룹 정책](glucose-management-policy.md)을 따른다.

- 음식명이 달라도 사전에 확정한 동일 그룹이면 그룹 점수만 인정한다.
- 같은 계열이라는 이유로 자동 인정하지 않는다. 명칭의 부분 문자열·tags·category_hint로
  그룹 정답을 만들지 않는다.
- 상위 이름만 식별한 경우는 부분 분류 지표에만 기록한다. 완전 그룹 정답에 합산하지 않는다.
- 정답 없는 음식은 그룹 분모에 넣지 않되, **그룹 정답 커버리지**와 미주석 음식 수를 반드시 보고한다.
- 정답이 있는 음식의 API 실패·누락·잘못된 그룹·미등록 예측은 정답 처리하지 않는다.
- 그룹 precision은 사진 전체 음식과 그룹 정답이 완비된 사진에서만 측정한다.
  recall과 범위가 다를 수 있으므로 함께 전체 정확도라고 해석하지 않는다.
- 정답이 하나도 없으면 점수는 null/NOT_MEASURED다. 0%나 100%라고 발표하지 않는다.

그룹 정의를 확대할 때는 영양 DB·제품 표시·확인된 조리법과 제한을 기록하고,
실행 전에 팀이 정답과 정책 버전을 확정한다. 새 가중치·임상 허용 오차·PASS 목표는 이번 변경에서 만들지 않았다.

## 출력과 해석

JSON 보고서의 `accuracy_summary`에 두 점수를 나란히 저장하고 CLI 상단에도 표시한다.
원래 `metrics`, `targets`, API 출력 스키마, 프롬프트, 모델 설정은 유지한다.

```text
음식명 정확도 (정답 음식 식별률): 맞춘 음식 수 / 정답 음식 수
혈당 관리용 특성 정확도 (정답 기록 그룹 식별률): 맞춘 그룹 수 / 그룹 정답 음식 수
혈당 관리 그룹 정답 커버리지: 그룹 정답 음식 수 / 전체 작성된 정답 음식 수
```

커버리지는 실제 사진 속 모든 음식 대비 비율이 아니라 **작성된 정답 음식 대비 비율**이다.
주석이 불완전한 데이터에서 실제 음식 전체 커버리지를 알 수는 없다.

예시 (자동 테스트의 합성 데이터, 실제 앱 성능이 아님):

| 정답 → 예측 | 음식명 | 기록 그룹 |
| --- | --- | --- |
| 일반 갈치구이 → 일반 고등어구이 | 불일치 | 기존 참고 비교 그룹 정답이 검수된 경우만 일치 |
| 일반 갈치구이 → 생선구이 | 불일치 | 부분 분류만, 완전 그룹 점수 0 |
| 일반 갈치구이 → 데리야키 생선구이 | 불일치 | 그룹 불일치 |
| 제로 콜라 → 일반 콜라 | 불일치 | 표시로 제품 종류를 확정한 정답에서 그룹 불일치 |

이는 동일한 혈당 반응이나 전체 영양 동등성을 인정한다는 뜻이 아니다.
떡볶이/치즈떡볶이, 삼계탕/닭곰탕 등은 아직 정의·검수된 그룹이 아니므로 자동으로 묶지 않는다.
현재 100장 라벨에는 그룹 정답이 없어 **음식명 71%, 혈당 관리용 특성 미측정**이다.
기존 결과·정답을 덮어쓰거나 추가 API 호출을 하지 않는다.

## 다음 작업

1. 불일치 사진과 기존 정답의 오류를 검수한다. 기존 71%를 사후 수정하지 않는다.
2. 적용할 수 있는 음식만 그룹 정답을 추가한 별도 라벨 버전을 만들고 근거·정책을 고정한다.
3. 동일 정답·모델·사진·이미지 설정으로 v3와 후보를 비교해 두 점수와 커버리지를 함께 보고한다.
4. 새 음식 그룹·치즈 유무 등 추가 특성은 근거 및 판정 기준을 합의한 뒤 별도 지표로 확장한다.
